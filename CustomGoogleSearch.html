Search via Custom API

Your API key is treated like a password. Keep it secure.

Enter your API Key, Search Engine ID, and a query, then click Search.

How to get your API Key and Search Engine ID

To use this search tool, you need credentials from Google Cloud and Programmable Search Engine:

  1. API Key:
    • Go to the Google Cloud Console.
    • Create a new project or select an existing one.
    • Navigate to "APIs & Services" > "Credentials".
    • Click "Create Credentials" and select "API key".
    • Important: Secure your API key! Restrict its usage to specific IP addresses or HTTP referrers in the Cloud Console if deploying this publicly.
    • Enable the "Custom Search API" for your project under "APIs & Services" > "Library". You can check its status or enable it here: Custom Search API Metrics.
  2. Search Engine ID (CX):
    • Go to the Programmable Search Engine control panel.
    • Click "Add" to create a new search engine.
    • Configure its settings (e.g., sites to search, look and feel).
    • Once created, find the "Search engine ID" in the "Basics" tab of the setup page.

Enter the generated API Key and Search Engine ID into the fields above.
